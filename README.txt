DHANAM - how to put it online (5 minutes)

FILES
  index.html  manifest.json  sw.js  icon-192.png  icon-512.png

STEP 1  github.com -> + -> New repository -> name DHANAM -> Public -> Create
STEP 2  Add file -> Upload files -> drag ALL 5 files -> Commit
STEP 3  Settings -> Pages -> Deploy from a branch -> main / (root) -> Save
STEP 4  open  https://karattiparakkalshafeeq-ui.github.io/DHANAM/
STEP 5  phone: Chrome -> menu -> Add to Home screen  (own icon, full screen, offline)

NOTE: data stays on the device. Settings -> Export backup regularly.
